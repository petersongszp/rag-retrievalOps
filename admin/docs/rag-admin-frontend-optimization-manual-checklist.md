# RAG 管理台前端优化人工验收清单

## 1. 全局入口

- 登录页不出现 `Phase / P3 / P4 / Feature Flags` 等研发阶段词。
- 侧边导航、面包屑、页面标题使用中文产品口径。
- 桌面与窄屏下无明显文字重叠、按钮溢出或抽屉遮挡操作。

## 2. 主路径页面

- 工作台：能看到系统状态、核心指标、待处理事项、快捷操作、趋势与风险。
- 知识库管理：空状态能创建知识库，详情页能上传文档、查看入库任务、处理失败任务。
- 检索调优：能输入问题，看到相关结果、引用来源、请求编号，并进入链路追踪与链路分析。
- 检索链路分析：无请求编号时有明确引导；有数据时能看到分阶段中文结果。
- 检索链路追踪 / 入库链路追踪：能按条件查询并打开详情。

## 3. 质量与治理

- 质量监控：没有成功评测时给出下一步动作；有报告时能看懂核心质量结论。
- 评测样本 / 评测任务 / 评测报告：状态、门禁、失败样本原因使用中文表达。
- 策略管理：风险、灰度、回退说明使用中文；高风险操作前有明确提示。
- 成本分析：能看到趋势、列表和高成本查询。
- 审计、告警、周报：空状态有下一步动作，详情内容可读。

## 4. 验证命令

- `npm run test --prefix admin`
- `npm run build --prefix admin`

## 5. 当前已知事项

- 仓库存在较多历史 `CRLF` 导致的 `prettier/prettier` 警告。
- `api-client.test.ts` 当前存在独立于本轮改动的 TypeScript 类型问题，需单独治理。
