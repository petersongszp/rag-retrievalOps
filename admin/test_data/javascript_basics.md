# JavaScript 基础入门

JavaScript 是一种轻量级、解释型的编程语言。它最初被设计用于网页浏览器中，使网页具有交互性。

## 变量声明

JavaScript 有三种变量声明方式：var、let 和 const。var 是函数作用域，let 和 const 是块级作用域。

## 数据类型

基本数据类型包括：string、number、boolean、null、undefined、symbol 和 bigint。引用类型包括 object、array 和 function。

## 函数

函数是 JavaScript 的一等公民。可以使用函数声明或箭头函数来定义。函数可以作为参数传递，也可以作为返回值返回。

## 异步编程

JavaScript 使用 Promise 和 async/await 来处理异步操作。Promise 有三种状态：pending、fulfilled 和 rejected。async/await 是 Promise 的语法糖，使异步代码看起来像同步代码。

## DOM 操作

Document Object Model 是 HTML 文档的编程接口。通过 document.getElementById、querySelector 等方法可以获取页面元素，并对其进行修改、添加或删除操作。
