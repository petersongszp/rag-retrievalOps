# Go 语言简介

## 什么是 Go 语言？

Go（又称 Golang）是 Google 开发的一种静态强类型、编译型语言。Go 语言语法与 C 相近，但功能上有：内存安全，GC（垃圾回收），结构形态及 CSP-style 并发计算。

## Go 语言的特点

1. **简洁、快速、安全**
2. **并行、有趣、开源**
3. **内存管理**
4. **数组安全、编译迅速**

## 历史

Go 语言起源 2007 年，并于 2009 年正式对外发布，由 Robert Griesemer、Rob Pike 和 Ken Thompson 设计。
