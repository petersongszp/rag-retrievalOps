## 3. 改进建议 (Suggestions)

### 7.2.2 动态追问机制
当前 `InterviewEngine.RunInterviewLoop` 使用硬编码的 for 循环 + `recentHistory` 切片实现动态上下文。建议：
```go
// 改进方案：使用 Eino StateGraph
graph := compose.NewStateGraph[InterviewState, InterviewState]()
graph.AddNode("generate_question", generateQuestionNode)
graph.AddNode("wait_answer", waitAnswerNode)
graph.AddEdge("generate_question", "wait_answer")
graph.AddConditionalEdge("wait_answer", shouldContinue, map[string]string{...})
```

### 7.2.3 对话控制
```go
// 建议添加 Guardrails
func validateUserInput(input string) error {
    // 1. 长度限制
    if len(input) > 5000 { return ErrInputTooLong }
    // 2. 关键词过滤 (SQL, eval, system prompt 等)
    if containsInjectionPattern(input) { return ErrPotentialInjection }
    // 3. 话题偏移检测 (可选)
    if isOffTopic(input, currentContext) { return ErrTopicDrift }
    return nil
}
```
