# 早日上岸AI智能面试平台开发实战课程

## 课程简介

欢迎参加「早日上岸AI智能面试平台」开发实战课程！本课程将带领你从零构建一个基于字节跳动Hertz框架和Eino大模型框架的完整AI面试系统。这是一个结合前沿AI技术与工程实践的实战项目，帮助你掌握Go语言后端开发、大模型应用集成以及现代Web架构设计。

## 项目概述

「早日上岸AI」是一个智能面试代理系统，利用大语言模型能力实现简历分析、面试问题生成、答案评估和报告生成等功能。系统采用微服务架构，后端基于Go语言开发，前端采用Next.js技术栈，提供流畅的用户体验和专业的面试服务，助力求职者早日获得理想工作。

## 核心技术栈

### 后端技术
- **语言**: Go 1.24
- **Web框架**: Hertz (字节跳动高性能HTTP框架)
- **AI框架**: Eino (大语言模型应用开发框架)
- **数据库**: 
  - MySQL + GORM (关系型数据存储)
  - Redis (缓存和会话管理)
  - Milvus (向量数据库，用于语义搜索和简历分析)
- **认证**: JWT (JSON Web Token)
- **API文档**: Swagger

### 前端技术
- **框架**: React.js 18.x + Next.js 14.x
- **UI组件**: Ant Design 5.x
- **类型系统**: TypeScript 5.x
- **状态管理**: Zustand + React Query
- **样式**: Tailwind CSS

## 系统功能特性

### 1. 多类型面试模式
- **综合面试**: 全面评估候选人的技术能力和综合素质
- **专项技术面试**: 针对特定技术栈（如Golang、前端、算法等）的深度考察
- **简历押题面试**: 基于用户上传的简历内容生成定制化问题

### 2. 智能简历分析
- 自动提取简历中的关键信息和技能点
- 识别项目经验和技术栈
- 生成针对性的面试问题建议

### 3. 专业评估体系
- 基于岗位要求的多维度评分
- 自动生成详细的面试报告
- 提供改进建议和技能提升方向

### 4. 真实面试体验
- 模拟大厂面试流程
- 支持实时问答和追问
- 语音交互（扩展功能）

## 架构设计亮点

### 微服务架构
系统采用清晰的微服务拆分，包括用户服务、面试管理服务、简历分析服务、AI交互服务和评估报告服务等，各模块职责明确，便于独立开发和部署。
