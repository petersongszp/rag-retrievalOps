**使用方法**

您现在可以通过以下步骤，让智能助手**tech-book-writer**帮您重写或撰写章节。这个技能已经“学会”了出版社的所有规矩（比如章首语、段落式写作、严禁PPT风格）。

**推荐的指令格式（直接发送给助手）：**

> "使用 tech-book-writer 技能，[动作] [章节号] [内容主题]。"

**实战演示（您可以直接复制发送）：**

**场景 1：重写被批评的第 1 章**
> "使用 tech-book-writer 技能，重写第 1 章的 1.1 和 1.2 节。请严格遵循出版社规范，特别是要有章首语，理论介绍要用 Who-What-Features-Value 模板，严禁使用 PPT 风格的列表。"

**场景 2：撰写新的技术章节**
> "使用 tech-book-writer 技能，撰写第 8 章关于 'Redis Stream 在多 Agent 通信中的应用'。请结合 backend/internal/mq/redis_queue.go 的代码，解释为什么选 Redis Stream 而不是 Kafka。"

**场景 3：优化特定段落**
> "使用 tech-book-writer 技能，优化这段关于 Eino Graph 的描述。现在的写法太像 PPT 了，请把它改成逻辑连贯的段落，并补充 Eino 的设计背景。"

---

**技能内部会自动执行以下流程（您无需操心）：**
1.  **复习班规**：先读一遍 `publisher_guidelines.md`。
2.  **查阅代码**：去项目里找真实的代码文件，确保不瞎编。
3.  **合规输出**：写出带有章首语、段落清晰、排版正确的书稿。
4.  **自我体检**：发给您之前，它会自己检查一遍“有没有用斜体？”“有没有解释新术语？”。

您可以现在就试试！
