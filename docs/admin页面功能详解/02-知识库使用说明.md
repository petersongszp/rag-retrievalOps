# 02-知识库使用说明

## 1. 页面用途

“知识库”相关页面用来管理知识库、文档和入库任务。

源码中包含两个主要页面：

1. **知识库列表页**：`/knowledge-bases`
2. **知识库详情页**：`/knowledge-bases/:id`

它们支持的操作包括：

- 查看知识库列表
- 新建知识库
- 打开知识库详情
- 删除知识库
- 查看知识库基础信息
- 上传文档
- 查看文档列表
- 删除文档
- 查看摄入任务列表
- 重试失败任务
- 取消未完成任务
- 跳转到检索实验室

## 2. 适合谁用

适合这些人使用：

- 需要新建知识库的人
- 需要上传 PDF、Markdown、TXT 文档的人
- 需要查看文档是否入库成功的人
- 需要处理失败入库任务的人
- 需要删除错误文档或删除整个知识库的人
- 需要进入检索实验室验证效果的人

## 3. 进入路径

### 3.1 知识库列表页

进入方式：

- 左侧菜单点击 **知识库**
- 或直接打开 `/knowledge-bases`

### 3.2 知识库详情页

进入方式：

- 在知识库列表页点击某个知识库卡片的 **打开**
- 在知识库列表页点击 **查看详情**
- 在顶部选择知识库后，如果当前已经在知识库详情页，会跳到新知识库详情页
- 直接打开 `/knowledge-bases/{知识库ID}`

## 4. 页面区域

## 4.1 知识库列表页区域

### 4.1.1 标题区

显示：

- 标题：**知识库**
- 描述：**这里展示知识库列表，并提供创建、删除和进入详情页的操作入口。**
- 按钮：**刷新**、**新建**

### 4.1.2 权限和错误提示区

如果加载失败但不是权限问题，会显示错误信息。

如果接口返回 403，会显示：

- **权限不足**
- **当前账号无权访问知识库列表（403）。请联系管理员确认权限配置。**

此时 **新建** 和 **删除** 按钮会被禁用。

### 4.1.3 知识库卡片区

每个知识库显示成一个卡片。

如果当前卡片对应顶部当前知识库，会加蓝色边框和轻微阴影。

卡片中展示：

- 名称
- 状态
- 描述
- Collection
- 创建时间
- 查看详情链接
- 打开按钮
- 删除按钮

如果没有知识库，页面显示空状态：

> 暂无知识库。新建一个以解锁详情页、文档流程和检索实验室。

## 4.2 新建知识库弹窗区域

点击 **新建** 后打开弹窗。

弹窗标题：**新建知识库**

包含字段：

- 名称
- 描述

按钮：

- **新建**
- **取消**

## 4.3 知识库详情页区域

### 4.3.1 不存在时的空状态

如果知识库列表已经加载完成，但找不到当前 ID 对应的知识库，页面显示：

> 请求的知识库不存在或暂不可用。

并提供按钮：**返回列表**。

### 4.3.2 权限和错误提示区

如果知识库数据接口返回 403，页面显示：

- **权限不足**
- **当前账号无权访问知识库数据（403）。请联系管理员确认权限配置。**

如果有其他错误，会以警告提示展示。

### 4.3.3 标题操作区

显示：

- 知识库名称；如果还未加载到名称，则显示 **知识库详情**
- 描述文字：**此路由承载了原单页管理后台的上传、文档及摄入任务管理流程。**
- 按钮：**刷新**、**打开检索实验室**、**Delete KB**、**上传文档**

注意：源码里详情页删除知识库按钮文字是英文 **Delete KB**，确认弹窗也是英文文案。

### 4.3.4 基础信息卡片

显示当前知识库的基础信息：

- 状态
- Collection
- 描述
- 创建时间

### 4.3.5 文档 Tab

Tab 名称格式：**文档（数量）**

表格列：

- 文件
- 类型
- 大小
- 分块数
- 文件哈希
- 状态
- 操作

### 4.3.6 摄入任务 Tab

Tab 名称格式：**摄入任务（数量）**

表格列：

- 任务 ID
- 文档 ID
- 状态
- 重试次数
- 开始时间
- 完成时间
- 错误信息
- 错误码
- 最近操作
- 操作

### 4.3.7 上传文档弹窗

点击 **上传文档** 后打开弹窗。

弹窗标题：**上传文档**

显示：

- 当前知识库名称；如果没有名称，显示 `#知识库ID`
- 选择文件按钮
- 支持格式提示：**PDF、MD、TXT、MARKDOWN**

按钮：

- **上传**
- **取消**

最多选择 10 个文件。

## 5. 字段 / 参数含义

## 5.1 知识库字段

知识库类型是 `KnowledgeBase`。

| 字段 | 页面位置 | 含义 | 页面如何展示 |
|---|---|---|---|
| `id` | 路由、打开详情 | 知识库 ID | 用于 `/knowledge-bases/:id` 跳转，不直接作为列表文字展示 |
| `name` | 列表卡片、详情标题、顶部选择器 | 知识库名称 | 直接展示 |
| `description` | 列表卡片、详情基础信息 | 描述 | 有值则展示；没有值显示“暂无描述。” |
| `vector_collection` | 列表卡片、详情基础信息 | 绑定的向量 collection 名称 | 有值则展示；没有值显示 `Contract gap` |
| `status` | 列表卡片、详情基础信息 | 知识库状态 | 用标签展示；`active` 用成功色，其它用默认色 |
| `created_at` | 列表卡片、详情基础信息 | 创建时间 | 页面直接展示接口返回值 |
| `updated_at` | 类型定义 | 更新时间 | 类型中存在，但本组页面没有直接展示 |

## 5.2 创建知识库弹窗字段

创建知识库提交的数据结构是：

| 字段 | 是否必填 | 页面文案 | 含义 |
|---|---|---|---|
| `name` | 必填 | 名称 | 知识库名称；为空会提示“请输入知识库名称” |
| `description` | 可选 | 描述 | 知识库描述信息 |

输入框提示：

- 名称：**示例：Go 面试指南**
- 描述：**可选，填写该知识库的描述信息**

提交接口：

- `POST /admin/kb/bases`

创建成功后：

1. 页面提示：`知识库"名称"已创建`
2. 自动刷新知识库列表
3. 自动选中新知识库
4. 自动跳转到 `/knowledge-bases/{新知识库ID}`

## 5.3 文档字段

文档类型是 `KBDocument`。

| 字段 | 页面位置 | 含义 | 页面如何展示 |
|---|---|---|---|
| `id` | 表格行 key、删除文档接口 | 文档 ID | 用于删除文档，不直接作为列展示 |
| `kb_id` | 类型定义、查询参数 | 所属知识库 ID | 查询文档时用 `kb_id` 过滤，本表未直接展示 |
| `file_name` | 文档表格“文件”列 | 文件名 | 显示文件图标和文件名 |
| `file_type` | 文档表格“类型”列 | 文件类型 | 转成大写标签；空值显示 `Contract gap` |
| `file_size` | 文档表格“大小”列 | 文件大小，单位字节 | 页面换算为 KB，并保留 2 位小数 |
| `file_hash` | 文档表格“文件哈希”列 | 文件哈希 | 有值展示；空值显示 `Contract gap` |
| `storage_path` | 类型定义 | 存储路径 | 类型中存在，但本页面未展示 |
| `status` | 文档表格“状态”列 | 文档处理状态 | 用标签展示 |
| `chunk_count` | 文档表格“分块数”列 | 文档切分后的块数量 | 有值展示；空值显示 `Contract gap` |
| `error_msg` | 类型定义 | 错误信息 | 类型中存在，但文档表格未展示该列 |
| `deleted` | 类型定义 | 删除标记 | 类型中存在，但本页面未展示 |
| `last_ingest_job_id` | 类型定义 | 最近入库任务 ID | 类型中存在，但本页面未展示 |
| `ingest_duration_ms` | 类型定义 | 入库耗时，单位毫秒 | 类型中存在，但本页面未展示 |
| `created_at` | 类型定义 | 创建时间 | 类型中存在，但本页面未展示 |
| `updated_at` | 类型定义 | 更新时间 | 类型中存在，但本页面未展示 |

文档状态类型来自源码：

- `pending`
- `processing`
- `completed`
- `failed`

页面颜色映射中还支持更多状态，见下方状态说明。

## 5.4 摄入任务字段

摄入任务类型是 `KBIngestJob`。

| 字段 | 页面位置 | 含义 | 页面如何展示 |
|---|---|---|---|
| `id` | 任务表格“任务 ID”列 | 任务 ID | 直接展示 |
| `kb_id` | 类型定义、查询接口 | 所属知识库 ID | 查询任务时用 `kb_id` 过滤，本表未直接展示 |
| `document_id` | 任务表格“文档 ID”列 | 关联文档 ID | 直接展示 |
| `user_id` | 类型定义 | 用户 ID | 类型中存在，但本页面未展示 |
| `status` | 任务表格“状态”列 | 任务状态 | 用标签展示 |
| `retry_count` | 任务表格“重试次数”列 | 已重试次数 | 有值展示；空值显示 `Contract gap` |
| `error_msg` | 任务表格“错误信息”列 | 错误信息 | 有值展示；空值显示 `Contract gap` |
| `last_error_code` | 任务表格“错误码”列 | 最近错误码 | 有值时用红色标签展示；没有值显示空 |
| `last_error_detail` | 类型定义 | 最近错误详情 | 类型中存在，但本页面未展示 |
| `operation` | 任务表格“最近操作”列 | 最近操作名称 | 有值时用标签展示；没有值显示空 |
| `operation_reason` | 类型定义 | 操作原因 | 类型中存在，但本页面未展示 |
| `operated_at` | 类型定义 | 操作时间 | 类型中存在，但本页面未展示 |
| `started_at` | 任务表格“开始时间”列 | 开始时间 | 有值展示；空值显示 `Contract gap` |
| `finished_at` | 任务表格“完成时间”列 | 完成时间 | 有值展示；空值显示 `Contract gap` |
| `created_at` | 类型定义 | 创建时间 | 类型中存在，但本页面未展示 |
| `updated_at` | 类型定义 | 更新时间 | 类型中存在，但本页面未展示 |

任务状态类型来自源码：

- `pending`
- `processing`
- `completed`
- `failed`
- `retrying`
- `dead`
- `canceled`

## 5.5 状态颜色说明

源码中状态颜色映射如下：

| 状态 | 颜色含义 |
|---|---|
| `pending` | 默认色 |
| `processing` | 处理中颜色 |
| `completed` | 成功色 |
| `failed` | 错误色 |
| `retrying` | 警告色 |
| `dead` | 错误色 |
| `canceled` | 默认色 |

## 5.6 上传文档参数

上传文档时，前端会提交 `FormData`。

| 参数 | 含义 |
|---|---|
| `kb_id` | 当前知识库 ID |
| `file` | 用户选择的文件，可以有多个 |

上传接口：

- `POST /admin/kb/documents/upload`

请求头：

- `Content-Type: multipart/form-data`

支持文件格式：

- `.pdf`
- `.md`
- `.txt`
- `.markdown`

最多选择：

- 10 个文件

## 6. 按钮 / 操作

## 6.1 知识库列表页按钮

### 刷新

位置：列表页右上角。

作用：重新加载知识库列表。

### 新建

位置：列表页右上角。

作用：打开 **新建知识库** 弹窗。

如果权限不足，该按钮禁用。

### 打开

位置：每个知识库卡片底部操作区。

作用：

1. 设置当前知识库为该知识库。
2. 跳转到 `/knowledge-bases/{id}`。

### 查看详情

位置：每个知识库卡片内容底部。

作用：跳转到 `/knowledge-bases/{id}`。

注意：源码中这个链接只负责跳转，没有显式调用 `setSelectedBaseId`；详情页加载后会设置当前知识库 ID。

### 删除

位置：每个知识库卡片底部操作区。

点击后弹出确认框：

- 标题：**删除知识库**
- 内容：`确认删除 "知识库名称"？这会同时清理它绑定的向量 collection 和已上传文档。`
- 确认按钮：**确认删除**
- 取消按钮：**取消**

删除接口：

- `DELETE /admin/kb/bases/{id}`

删除成功后：

1. 页面提示：**知识库已删除**
2. 自动刷新知识库列表
3. 如果删除的是当前选中知识库，会自动选择列表中的第一个知识库，或清空选择

## 6.2 新建知识库弹窗按钮

### 新建

作用：提交表单。

如果名称为空，会提示：**请输入知识库名称**。

### 取消

作用：关闭弹窗并清空表单。

## 6.3 知识库详情页按钮

### 刷新

作用：重新加载文档列表和摄入任务列表。

### 打开检索实验室

作用：跳转到 `/retrieval-lab`。

### Delete KB

作用：删除当前知识库。

点击后弹出确认框：

- 标题：**Delete Knowledge Base**
- 内容：`Delete "知识库名称" and its bound vector collection?`
- 确认按钮：**Delete**
- 取消按钮：**Cancel**

删除成功后跳转到 `/knowledge-bases`。

### 上传文档

作用：打开上传文档弹窗。

如果权限不足，该按钮禁用。

## 6.4 文档表格操作

### 删除文档

点击文档行的 **删除** 按钮后弹出确认框：

- 标题：**删除文档**
- 内容：`确认删除"文件名"？此操作不可撤销。`
- 确认按钮：**确认删除**
- 取消按钮：**取消**

删除接口：

- `DELETE /admin/kb/documents/{文档ID}`

删除成功后：

1. 页面提示：**文档已删除**
2. 刷新详情数据

## 6.5 摄入任务表格操作

### 重试

显示条件：任务状态是 `failed` 或 `dead`。

点击后弹出确认框：

- 标题：**重试任务**
- 内容：`确认重试任务 任务ID？`
- 确认按钮：**确认重试**
- 取消按钮：**取消**

接口：

- `POST /admin/kb/jobs/{任务ID}/retry`

成功后提示：`已请求重试任务 任务ID`

### 取消

显示条件：任务状态不是以下状态：

- `completed`
- `canceled`
- `dead`

也就是说，`pending`、`processing`、`failed`、`retrying` 等状态会显示取消按钮。

点击后弹出确认框：

- 标题：**取消任务**
- 内容：`确认取消任务 任务ID？`
- 确认按钮：**确认取消**
- 取消按钮：**返回**

接口：

- `POST /admin/kb/jobs/{任务ID}/cancel`

成功后提示：`任务 任务ID 已取消`

## 6.6 上传文档弹窗按钮

### 选择文件

作用：选择要上传的文件。

限制：

- 支持 PDF、MD、TXT、MARKDOWN
- 最多 10 个文件
- 文件不会在选择后立刻上传，而是等待点击 **上传**

### 上传

作用：提交文件。

如果没有选择文件，会提示：**请至少选择一个文件**。

上传成功后：

1. 页面提示：**上传成功，正在刷新文档和任务列表...**
2. 关闭弹窗
3. 清空已选择文件
4. 刷新文档和任务列表

### 取消

作用：关闭弹窗并清空文件列表。

如果正在上传中，取消操作不会生效。

## 7. 可展开 / 弹窗 / 详情页

### 7.1 新建知识库弹窗

从列表页点击 **新建** 打开。

包含名称和描述两个字段。

### 7.2 删除知识库确认弹窗

列表页和详情页都有删除知识库确认弹窗。

区别：

- 列表页确认文案是中文。
- 详情页确认文案是英文。

### 7.3 上传文档弹窗

从详情页点击 **上传文档** 打开。

选择文件后需要点击 **上传** 才会真正提交。

### 7.4 删除文档确认弹窗

从文档表格点击 **删除** 打开。

### 7.5 重试 / 取消任务确认弹窗

从摄入任务表格点击 **重试** 或 **取消** 打开。

### 7.6 文档和摄入任务 Tab

详情页使用 Tab 切换：

- 文档
- 摄入任务

Tab 标题中会显示当前列表数量。

### 7.7 自动轮询任务

如果任务列表中有活动状态任务，前端会每 3 秒刷新一次任务列表。

活动状态包括：

- `pending`
- `processing`
- `retrying`

如果没有活动任务，会停止自动轮询。

## 8. 常见流程

### 流程一：新建一个知识库

1. 进入 `/knowledge-bases`。
2. 点击 **新建**。
3. 填写 **名称**。
4. 可选填写 **描述**。
5. 点击 **新建**。
6. 创建成功后自动进入新知识库详情页。

### 流程二：打开已有知识库

1. 进入 `/knowledge-bases`。
2. 找到目标知识库卡片。
3. 点击 **打开** 或 **查看详情**。
4. 进入详情页。

### 流程三：上传文档

1. 进入某个知识库详情页。
2. 点击 **上传文档**。
3. 点击 **选择文件**。
4. 选择 PDF、MD、TXT 或 MARKDOWN 文件，最多 10 个。
5. 点击 **上传**。
6. 上传成功后查看文档列表和摄入任务列表。

### 流程四：查看文档是否入库完成

1. 进入知识库详情页。
2. 打开 **文档** Tab。
3. 查看文档状态。
4. 打开 **摄入任务** Tab。
5. 查看任务状态、错误信息、错误码、开始时间和完成时间。

### 流程五：重试失败任务

1. 进入知识库详情页。
2. 打开 **摄入任务** Tab。
3. 找到状态为 `failed` 或 `dead` 的任务。
4. 点击 **重试**。
5. 在弹窗中点击 **确认重试**。

### 流程六：取消未完成任务

1. 进入知识库详情页。
2. 打开 **摄入任务** Tab。
3. 找到可取消的任务。
4. 点击 **取消**。
5. 在弹窗中点击 **确认取消**。

### 流程七：删除文档

1. 进入知识库详情页。
2. 打开 **文档** Tab。
3. 找到要删除的文档。
4. 点击 **删除**。
5. 在弹窗中点击 **确认删除**。

### 流程八：删除知识库

1. 进入知识库列表页或详情页。
2. 点击知识库的 **删除** 或 **Delete KB**。
3. 仔细阅读确认弹窗。
4. 确认后删除。

## 9. 注意事项

- 删除知识库会同时清理它绑定的向量 collection 和已上传文档；这是列表页确认弹窗明确提示的内容。
- 删除文档弹窗提示“此操作不可撤销”。
- 上传文件选择后不会自动上传，必须点击弹窗里的 **上传**。
- 上传文档时至少要选择一个文件，否则会提示“请至少选择一个文件”。
- 上传弹窗最多选择 10 个文件。
- 支持格式来自源码：PDF、MD、TXT、MARKDOWN。
- 详情页任务列表如果存在 `pending`、`processing`、`retrying` 状态，会每 3 秒自动刷新任务列表。
- `Contract gap` 表示接口返回字段为空、缺失或当前契约有空缺，页面只是把它显示出来。
- 权限不足时，新建、删除、上传、重试、取消等操作会被禁用或显示权限提示。
- 详情页删除知识库按钮和确认弹窗是英文，这是源码中的实际文案。

## 10. 术语速查

| 术语 | 简单解释 |
|---|---|
| 知识库 | 一组用于检索和问答的文档集合 |
| 知识库 ID | 知识库的唯一编号，用在详情页路径里 |
| Collection | 向量数据库中的集合名称 |
| 文档 | 上传到知识库中的文件 |
| 摄入任务 / 入库任务 | 把文档解析、切分并写入向量库的任务 |
| 分块数 | 文档被切成多少个文本块 |
| 文件哈希 | 用来识别文件内容的哈希值 |
| 状态 `pending` | 等待处理 |
| 状态 `processing` | 正在处理 |
| 状态 `completed` | 已完成 |
| 状态 `failed` | 失败 |
| 状态 `retrying` | 正在重试 |
| 状态 `dead` | 任务已进入不可自动恢复的失败状态 |
| 状态 `canceled` | 已取消 |
| 重试 | 对失败或 dead 任务重新发起处理 |
| 取消 | 停止还没有最终完成的任务 |
| Contract gap | 页面兜底显示，表示字段没有值或接口契约暂缺 |
