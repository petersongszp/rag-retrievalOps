# 面试吧 · AI智能面试实战营（知识星球课程方案）

> 基于真实开源项目「面试吧」全栈落地：Hertz 后端 + Eino AI 智能体 + Milvus 向量检索 + Redis 队列 + Next.js 前端 + Docker 部署。面向求职者与在职工程师，以“能产出可展示的面试作品集”为目标。

## 星球名称
- 面试吧 · AI智能面试实战营

## 星球简介
- 「面试吧」是一个围绕真实工程项目的实战型知识星球，帮助你系统掌握 AI 驱动的面试系统从 0 到 1 的落地能力。你将完成一套可上线展示的作品：包括简历分析、面试问题生成、答案评估、专项/综合面试、评估报告与可视化前端，并掌握工程化能力（鉴权、存储、缓存、消息队列、检索、部署）。

## 星球亮点
- 实战驱动：以真实代码库为主线，模块化拆解、逐步交付可用功能
- AI+面试融合：Eino 智能体、Embedding、向量检索、问答评估完整链路
- 企业级工程：Hertz、高内聚分层、JWT、Redis 队列、Docker 一键部署
- 求职导向：专项面试（Java/Go/DB/Redis/MQ）、综合面试、简历押题与评估
- 完整资料：源码、讲义、答疑、作业批改、简历打磨与面试作品集
- 可验证成果：上线演示、接口文档、PR记录与里程碑任务

## 适合人群
- 目标互联网研发岗的在校/毕业生，希望以项目增强面试竞争力
- 在职工程师，希望掌握 AIGC 与检索增强落地、打造团队样板项目
- 具备基础编程能力（Go/TypeScript 其一），希望系统提升工程化能力

## 学习目标（产出导向）
- 独立搭建并上线「面试吧」项目，形成可展示 Demo 与作品集
- 掌握 Eino 智能体编排、Embedding、Milvus 检索、Redis 队列
- 熟悉 Hertz/Web API 设计、JWT 鉴权、MySQL/GORM、错误与日志治理
- 能编写 Next.js 前端页面，完成接口对接与交互
- 具备 Docker 化与 Nginx 反向代理能力，实现一键部署

## 项目技术栈（与代码库一致）
- 后端：`Hertz`、`GORM/MySQL`、`Redis`、`JWT`
- AI 框架：`Eino`、模型管理、Embedding、检索增强
- 向量数据库：`Milvus`
- 前端：`Next.js + TypeScript + Tailwind`
- 工程化：`Docker`、`docker-compose`、`Nginx`

## 课程结构（8 周）
- 第 0 周｜开营与环境准备
  - 克隆与跑通项目；配置 `backend/config.yaml`、`.env`；了解模块架构
- 第 1 周｜后端基础与鉴权
  - 路由与中间件、JWT 登录、用户中心、错误与日志治理
- 第 2 周｜AI 智能体与模型管理
  - Eino 智能体编排、模型管理（加载、切换）、OpenAI/Ark 对接
- 第 3 周｜Embedding 与向量检索
  - 文档导入与分割、Milvus 建索引与检索、知识库问答
- 第 4 周｜面试核心能力
  - 综合/专项面试流：问题生成、答案评估、记录与报告
- 第 5 周｜前端与交互
  - Next.js 页面与路由、状态管理、接口对接、评估可视化
- 第 6 周｜消息队列与异步处理
  - Redis 队列、消费者与重试、任务编排与性能调优
- 第 7 周｜部署与作品集
  - Docker 化、Nginx 反代、线上演示站、个人作品集与简历打磨

## 模块与里程碑（对应仓库结构）
- 用户与鉴权：`backend/api/router`、`internal/middleware/jwt.go`
- 面试服务：`backend/api/handler/interview`、`internal/service/interviews`
- 智能体与评估：`backend/chatApp/agent/*`、`agent_service/*`
- 检索增强：`internal/eino/milvus/*`（导入、索引、检索、Splitter）
- 队列与异步：`internal/mq/*`（生产者/消费者、Redis 队列）
- 前端页面：`frontend/src/app/*`（面试、简历、评估、用户中心）
- 部署脚本：`docker-compose*.yml`、`nginx.conf`
