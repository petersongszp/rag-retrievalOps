- chatApp 目录既有 `main.go`（独立应用）
- 又被 `internal/service` 依赖（作为库）

## 会议议程建议

### 第一部分：关键决策（30分钟）

1. **Redis/Milvus 启用问题**（10分钟）
   - 决定是否启用
   - 如果启用，时间表
   - 如果不启用，替代方案

2. **龙哥的项目融合**（10分钟）
   - 项目介绍
   - 融合方案
   - 责任人和时间表

3. **人员分工**（10分钟）
   - 明确每个人的职责
   - 工作量评估
   - 并行开发计划

### 第二部分：技术讨论（30分钟）

4. **架构优化方案**（15分钟）
   - 模块重构计划
   - 优先级确认
   - 风险评估

5. **测试和质量保障**（15分钟）
   - 测试策略
   - 代码审查流程
   - 质量标准

### 第三部分：计划制定（30分钟）

6. **优化计划确认**（15分钟）
   - 哪些优化立即开始？
   - 哪些可以延后？
   - 时间表和里程碑

7. **资源和支持**（15分钟）
   - 需要什么资源？
   - 遇到问题如何解决？
   - 定期同步机制
