## 📊 项目功能现状分析

### ✅ 已实现功能（项目中有的）

| 功能模块 | 具体实现 |
|---------|---------|
| **混合检索** | Dense + Sparse 双路召回，权重可调 |
| **重排序** | Jaccard 相似度重排序（非 Cross-Encoder） |
| **动态 TopK** | 基于查询特征的规则性策略 + 基于检索结果的策略性调整 |
| **父子文档** | Markdown 层级识别 + 检索时上下文补全 |
| **查询重写** | 术语扩展、问题澄清、模型辅助重写 + 影子模式验证 |
| **评估体系** | Recall@K、MRR、NDCG、引用准确率、拒绝准确率等 |
| **可观测性** | Prometheus 20+ 核心指标 + 评估报告生成 |
| **A/B 实验** | 流量灰度、按知识库/查询类型定向、自动回滚 |
| **多租户** | 数据隔离、权限管控、配额限制 |
| **索引管理** | 版本管理、灰度切换、一键回滚 |
| **证据门控** | 基于证据密度、引用一致性的质量过滤 |
| **异步处理** | Redis Stream 任务队列 |
| **SDK** | Go 语言 SDK 封装 |

| **知识图谱增强检索** | 基于实体关系的关联召回，补充语义信息 | ⭐⭐⭐⭐ |
