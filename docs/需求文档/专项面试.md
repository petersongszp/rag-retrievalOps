# 专项面试模块

## 模块概述
专项面试模块专注于针对特定技术领域进行深度评估，帮助用户查漏补缺，提升在特定专业方向上的竞争力，为技术面试做好充分准备。

## 功能详情

### 1. 技术领域分类
- 支持多个热门技术领域的专项面试
  - Java（基础、高级特性、框架等）
  - Golang（语法、并发、标准库等）
  - Redis（数据结构、性能优化、应用场景等）
  - MySQL（索引优化、事务、锁机制等）
  - 消息队列（Kafka、RabbitMQ等）
  - JavaScript/前端技术栈
  - C++
  - 计算机网络
  - 操作系统
  - MongoDB
  - 测试平台开发

### 2. 深度技术问题生成
- 根据选择的技术领域自动生成针对性问题
- 问题难度可设置（入门、进阶、挑战）
- 支持问题深度递进，由浅入深
- 问题覆盖理论知识和实践应用

### 3. 垂直领域能力评估
- 针对特定技术领域的知识点覆盖率分析
- 实践经验深度评估
- 问题解决思路与方法评估
- 代码能力评估（部分领域）

### 4. 弱点分析与强化建议
- 技术知识点薄弱项识别
- 提供个性化学习资源推荐
- 针对性练习题目推荐
- 学习路径规划建议

## 流程设计
1. 用户选择技术领域
2. 设置面试参数（难度、时长等）
3. 开始专项面试
4. AI面试官提问，用户回答
5. 面试结束后生成详细评估报告
6. 查看弱点分析和改进建议
