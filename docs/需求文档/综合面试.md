# 综合面试模块

## 模块概述
综合面试模块模拟真实的大厂面试流程，对用户的专业能力、沟通技巧、解决问题能力等多方面进行全方位评估，提供全面的面试体验和详细的反馈报告，帮助用户在真实面试中表现出色。

## 功能详情

### 1. 多维度能力评估
- 专业知识评估（技术广度和深度）
- 沟通表达能力评估
- 问题解决思路和方法评估
- 逻辑思维能力评估
- 学习能力和潜力评估
- 压力应对能力评估

### 2. 模拟真实面试流程
- 还原大厂真实面试环节（技术面、HR面等）
- 支持多轮面试，难度递进
- 实时追问机制，模拟真实面试场景
- 时间限制和压力模拟

### 3. 面试过程录制与回放
- 面试全程文字记录
- 语音记录和回放（可选）
- 关键问题标记和回顾
- 面试表现关键时刻截取

### 4. 实时反馈与评分
- 面试结束后生成详细评分报告
- 各维度能力雷达图展示
- 回答质量分析和评分依据
- 与同行业平均水平对比
- 个性化改进建议

### 5. 面试难度设置
- 支持入门、进阶、挑战三个难度级别
- 可根据目标公司和岗位调整难度
- 支持自定义面试时长
- 问题数量和类型可配置

## 流程设计
1. 用户选择综合面试
2. 设置面试参数（难度、时长、目标岗位等）
3. 开始模拟面试
4. AI面试官提问，用户作答
5. AI根据回答进行实时追问
6. 面试结束，生成综合评估报告
7. 用户查看报告，获取改进建议
8. 可选择针对弱项进行专项练习
