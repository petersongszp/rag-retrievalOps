# 功能组件拆分

## 基础功能
- 用户系统
  - 注册/登录（支持邮箱/手机号）
  - 用户信息管理（个人资料、头像等）
  - 角色权限管理（普通用户、管理员）

- 文件处理
  - 上传PDF简历
  - 简历解析与信息提取
  - 文件存储与管理

- 语音交互 
  - 语音输入转文字
  - 文字转语音输出
  - 语音质量优化

- AI模型集成
  - 通用模型接入框架
  - 模型性能监控
  - 多模型支持与切换

## 核心面试功能
- 综合面试模块
  - 多维度能力评估（专业知识、沟通技巧、解决问题能力）
  - 模拟真实面试流程
  - 面试过程录制与回放
  - 实时反馈与评分

- 专项面试模块
  - 技术领域分类（Java、Golang、Redis、MySQL等）
  - 深度技术问题生成
  - 垂直领域能力评估
  - 弱点分析与强化建议

- 简历押题模块
  - 简历智能分析
  - 个性化面试题预测
  - 简历相关项目深度挖掘
  - 押题准确率统计

- 面试题库
  - 题目分类与标签系统
  - 题目搜索与筛选
  - 题目详情与解析
  - 热门题库推荐

## 辅助功能
- 招聘公司和岗位信息管理
  - 公司信息录入与展示
  - 岗位要求分析
  - 公司面试风格匹配

- 邀请有礼
  - 邀请码生成与管理
  - 邀请记录追踪
  - 奖励规则配置
  - 奖励发放管理

- 学习报告
  - 面试数据统计分析
  - 能力雷达图展示
  - 进步趋势追踪
  - 个性化改进建议

- 系统配置
  - 难度级别设置（入门/进阶/挑战）
  - 面试时长配置
  - 评分标准设置
  - 系统参数优化
