# 用户模型管理端到端教学

## 课程目标
- 为每个用户实现“模型配置 → 默认模型启用 → 校验”的完整闭环
- 让后续简历解析智能体能读取用户自己的默认模型并调用

## 模块边界
- 存储：`backend/internal/model/user_model.go`
- 服务：`backend/internal/service/user/impl/user_model_impl.go`
- Handler：`backend/api/handler/interview/user_service.go`
- 路由：`backend/api/router/interview/api.go`（`/api/user/*` 分组）
- Agent 读取点：`backend/chatApp/chat/openAi.go`

## 接口与路由
- 创建模型：`POST /api/user/create/model`（`backend/api/router/interview/api.go:71-73`）
- 模型列表：`GET /api/user/model/list`（`backend/api/router/interview/api.go:76-77`）
- 模型详情：`GET /api/user/model/details/:id`（`backend/api/router/interview/api.go:83-85`）
- 更新模型：`PUT /api/user/model/update/:id`（`backend/api/router/interview/api.go:87-89`）
- 删除模型：`DELETE /api/user/model/delete/:id`（`backend/api/router/interview/api.go:79-81`）
- 检查是否配置默认模型：`GET /api/user/model/check`（Handler `backend/api/handler/interview/user_service.go:347-383`）

## 核心数据结构
- `UserModel`（`backend/internal/model/user_model.go:24-46`）：
  - 关键字段：`ModelKey`、`Protocol`、`BaseURL`、`APIKeyEncrypted`、`ProviderName`、`IsDefault`
  - DAO 能力：`SetDefaultUserModel`、`GetDefaultUserModel`、`CancelDefaultUserModel`、`SetEnabledUserModel`

## 服务实现要点
- 创建时加密 APIKey：`common.EncryptAPIKey`（`backend/internal/service/user/impl/user_model_impl.go:23-31`）
- 若 `is_default=1`，先取消其他默认：`CancelDefaultUserModel(userID, 0)`（同文件）
- 更新时支持切换默认与启用状态：`SetDefaultUserModel`、`SetEnabledUserModel`（同文件）
- 检查默认模型：`CheckUserModelConfigured` 返回 `nil` 表示未配置（同文件）

## Agent 对接
- 智能体取用户默认模型：`chat.CreatOpenAiChatModel(ctx, userId)`（`backend/chatApp/chat/openAi.go:12-60`）
- 流程：读取默认模型 → 解密密钥 `common.DecryptAPIKey` → 构建 `openai.NewChatModel`
- 兼容 OpenAI 风格 BaseURL；其他协议可后续扩展为工厂方法

## 与上传简历的衔接
- 上传入口强制检查默认模型：`backend/api/handler/interview/interviews_service.go:56-91`（新增默认模型校验）
- 未配置默认模型返回：`400 请先在用户模型管理中配置并启用默认模型`

## 开发顺序（40–60 分钟）
- 第 1 步：建表与模型（讲解字段与索引）
- 第 2 步：实现 DAO 方法（默认/启用状态切换）
- 第 3 步：实现 Service（创建加密、更新切换、删除、列表、详情、检查）
- 第 4 步：绑定 Handler 与路由（对照 IDL 注解路径）
- 第 5 步：联通 Agent（本地演示从默认模型到 ChatModel 构建）
- 第 6 步：与简历上传联调（未配置提示 + 正常流程）

## 演示命令
- 创建默认模型：
  ```bash
  curl -X POST -H "Authorization: Bearer <token>" \
    -F "name=MyOpenAI" -F "model_key=gpt-4o-mini" \
    -F "protocol=openai" -F "base_url=https://api.openai.com/v1" \
    -F "api_key=sk-..." -F "provider_name=OpenAI" -F "is_default=1" \
    http://localhost:<port>/api/user/create/model
  ```
- 检查是否已配置：`GET /api/user/model/check`
- 上传简历（已配置后）：`POST /api/resume/upload`（携带 PDF）

## 易错项
- 未加密存储 APIKey → 必须加密，并且读取时解密
- 默认模型切换要取消其他默认状态
- Agent 取模型失败要区分：未配置、密钥错误、配额不足、限速

## 扩展建议
- 支持多协议工厂：根据 `Protocol` 构建对应 ChatModel（OpenAI/Ark/Claude/DeepSeek 等）
- 密钥脱敏显示：`SecretHint` 字段仅回显末尾4位
- 审计与告警：默认模型变更、失败率统计、配额告警
