# 01-概览使用说明

## 1. 页面用途

“概览”页面是 Admin 前端的首页，用来快速查看知识库系统的整体状态。

它主要展示：

- 当前选中的知识库
- 知识库数量
- 文档数量
- 正在处理的任务数量
- 失败任务数量
- 成本、审计、告警入口
- 知识库管理和检索实验室入口
- 监控指标趋势
- 失败类型 TopN

## 2. 适合谁用

适合这些人使用：

- 想快速了解系统是否正常的人
- 想看知识库和文档总量的人
- 想检查是否有失败任务的人
- 想进入知识库管理、检索实验室的人
- 想查看入库成功率、检索请求量、检索耗时、空结果率、成本指标的人

## 3. 进入路径

进入路径：

- 左侧菜单点击 **概览**
- 或直接打开 `/dashboard`

## 4. 页面区域

### 4.1 页面标题区

页面顶部显示：

- 标题：**概览**
- 当前知识库：显示当前选中的知识库名称；如果没有选择，则显示 **未选择**
- 按钮：**刷新页面**

点击 **刷新页面** 会执行页面刷新。

### 4.2 权限和错误提示区

如果知识库列表接口返回 403，页面显示：

- **权限不足**
- **当前账号无权访问知识库列表（403）。请联系管理员确认权限配置。**

如果概览统计接口返回 403，页面显示：

- **权限不足**
- **当前账号无权访问概览统计数据（403）。请联系管理员确认权限配置。**

如果统计接口发生其他错误，页面会显示错误消息。

### 4.3 总体统计卡片区

页面有 4 个主要统计卡片：

1. **知识库**
2. **文档**
3. **处理中任务**
4. **失败任务**

这些数据来自概览统计接口。

### 4.4 治理入口卡片区

页面还有 3 个治理相关入口：

1. **P4 成本治理**
2. **审计覆盖入口**
3. **治理告警入口**

点击后会进入对应页面。

### 4.5 快捷入口区

页面提供两个快捷入口：

1. **知识库管理**
2. **检索实验室**

### 4.6 监控指标区

监控指标区展示：

- 入库成功率
- 检索请求量
- 检索 P95
- 空结果率
- 每千次问答成本
- 失败类型 TopN

右上角可以切换时间窗：

- `1h`
- `24h`
- `7d`

默认时间窗是 `24h`。

## 5. 字段 / 参数含义

### 5.1 概览统计字段

概览统计接口返回的数据结构在源码中定义为 `DashboardStats`。

| 字段 | 页面名称 | 含义 |
|---|---|---|
| `kb_count` | 知识库 | 当前系统中的知识库数量 |
| `document_count` | 文档 | 当前系统中的文档数量 |
| `processing_job_count` | 处理中任务 | 当前正在处理的入库任务数量 |
| `failed_job_count` | 失败任务 | 当前失败的入库任务数量 |

### 5.2 监控接口参数

监控指标接口会带这些参数：

| 参数 | 含义 | 页面来源 |
|---|---|---|
| `range` | 时间窗 | 用户在 `1h / 24h / 7d` 中选择 |
| `kb_id` | 知识库 ID | 如果顶部有当前知识库，则带上当前知识库 ID；没有选择则不带 |

### 5.3 监控指标字段

监控指标数据类型是 `MetricsOverview`。

| 字段 | 页面显示 | 含义 |
|---|---|---|
| `range` | 时间窗 | 当前统计范围，如 `1h`、`24h`、`7d` |
| `ingest_success_rate` | 入库成功率 | 每个时间桶的入库成功率 |
| `retrieve_request_count` | 检索请求量 | 每个时间桶的检索次数 |
| `retrieve_p95_ms` | 检索 P95 | 每个时间桶的 P95 检索耗时，单位毫秒 |
| `retrieve_empty_rate` | 空结果率 | 每个时间桶的无结果比例 |
| `error_type_topn` | 失败类型 TopN | 当前时间窗内失败类型排行 |
| `cost_overview` | 每千次问答成本 | 成本相关趋势数据，源码中该字段是可选字段 |

### 5.4 时间桶字段

页面会把接口返回的 `bucket` 转成展示标签。

| 字段 | 含义 |
|---|---|
| `bucket` | 时间桶，页面会格式化成小时或日期时间 |
| `rate` | 比率，例如成功率、空结果率 |
| `count` | 数量，例如检索请求数 |
| `p95_ms` | P95 耗时，单位毫秒 |
| `cost_per_1k_queries` | 每千次问答成本 |
| `avg_context_tokens` | 平均上下文 token 数 |

### 5.5 失败类型字段

失败类型 TopN 使用 `error_type_topn`。

| 字段 | 含义 | 页面如何展示 |
|---|---|---|
| `error_code` | 错误码 | 作为失败类型名称展示 |
| `count` | 出现次数 | 作为数量展示，并用进度条样式显示比例 |

## 6. 按钮 / 操作

### 6.1 刷新页面

位置：页面右上角。

按钮文字：**刷新页面**。

作用：刷新当前页面。

### 6.2 点击“知识库”统计卡片

点击后跳转：`/knowledge-bases`

页面提示：**点击管理知识库**。

### 6.3 点击“文档”统计卡片

点击后跳转：`/knowledge-bases`

页面提示：**点击查看文档列表**。

注意：源码中这里跳转到知识库列表，不是直接跳到某个文档列表。

### 6.4 点击“处理中任务”统计卡片

跳转规则：

- 如果当前已选择知识库：跳到 `/knowledge-bases/{当前知识库ID}`
- 如果未选择知识库：跳到 `/knowledge-bases`

页面提示：**点击查看任务队列**。

### 6.5 点击“失败任务”统计卡片

跳转规则同“处理中任务”。

页面提示：**点击查看失败任务**。

如果失败任务数量大于 0，数字会用红色样式，并显示警告图标。

### 6.6 点击治理入口卡片

| 卡片 | 跳转路径 | 页面提示 |
|---|---|---|
| P4 成本治理 | `/cost-ops/cost` | 打开成本看板与高成本 Query |
| 审计覆盖入口 | `/audit` | 查看审计事件、脱敏详情与导出 |
| 治理告警入口 | `/alerts` | 查看告警确认、解决与治理门禁 |

### 6.7 快捷入口“打开”

| 卡片 | 打开路径 | 说明 |
|---|---|---|
| 知识库管理 | `/knowledge-bases` | 管理知识库与文档，上传文件并触发入库任务 |
| 检索实验室 | `/retrieval-lab` | 运行检索测试，验证入库效果与召回质量 |

### 6.8 切换监控时间窗

在监控指标右上角点击：

- `1h`
- `24h`
- `7d`

页面会重新请求监控指标接口。

## 7. 可展开 / 弹窗 / 详情页

### 7.1 趋势小图

每个趋势指标卡片中有一条小折线图。

如果没有数据，会显示：**暂无数据**。

### 7.2 失败类型 TopN

如果没有失败日志，会显示：**当前时间窗内没有失败日志**。

如果有失败日志，会展示错误码和数量。

### 7.3 本页面没有弹窗

根据源码，概览页面本身没有新增、删除、确认类弹窗。

### 7.4 可跳转详情页

概览页面的“处理中任务”和“失败任务”卡片可以跳到知识库详情页。知识库详情页里有文档列表和摄入任务列表。

## 8. 常见流程

### 流程一：查看系统是否有失败任务

1. 进入 `/dashboard`。
2. 看 **失败任务** 卡片。
3. 如果数量大于 0，点击该卡片。
4. 进入知识库详情页或知识库列表，继续查看任务。

### 流程二：查看当前知识库的监控情况

1. 在顶部选择当前知识库。
2. 进入 **概览**。
3. 在监控指标区选择时间窗，比如 `24h`。
4. 查看入库成功率、检索请求量、检索 P95、空结果率和成本。

### 流程三：进入知识库管理

1. 进入概览页。
2. 点击 **知识库** 统计卡片，或点击 **知识库管理** 卡片右上角的 **打开**。
3. 进入 `/knowledge-bases`。

### 流程四：进入检索实验室

1. 进入概览页。
2. 点击 **检索实验室** 卡片右上角的 **打开**。
3. 进入 `/retrieval-lab`。

## 9. 注意事项

- 概览统计和监控指标是两个不同接口，可能一个加载成功，另一个加载失败。
- 监控指标默认时间窗是 `24h`。
- 如果顶部选择了知识库，监控指标请求会带 `kb_id`；如果没有选择，就不带 `kb_id`。
- `7d` 时间窗的时间标签会显示月/日和小时；`1h`、`24h` 的时间标签显示小时和分钟。
- 入库成功率和空结果率在页面上以百分比显示，比如 `95.0%`。
- 检索 P95 单位是毫秒，页面显示为 `xxx ms`。
- 成本卡片显示的是 `cost_per_1k_queries`，页面格式为 `$数字`。
- 如果没有监控数据，趋势图区域显示“暂无数据”。

## 10. 术语速查

| 术语 | 简单解释 |
|---|---|
| 概览 | 后台首页，用来快速看整体状态 |
| 知识库数量 | 系统里已有多少个知识库 |
| 文档数量 | 系统里已有多少份文档 |
| 处理中任务 | 正在入库、解析、切分或写入向量库的任务 |
| 失败任务 | 入库过程中失败的任务 |
| 时间窗 | 指标统计的时间范围，如 `1h`、`24h`、`7d` |
| 入库成功率 | 已结束任务中成功完成的比例 |
| 检索请求量 | 当前时间窗内发生了多少次检索 |
| P95 | 95% 请求都不超过的耗时值，常用于看性能 |
| 空结果率 | 检索没有结果的比例 |
| Token | 模型处理文本时使用的基本计量单位 |
| 每千次问答成本 | 每 1000 次问答估算成本 |
| TopN | 排名前 N 的项目 |
| 错误码 | 表示失败类型的代码 |
