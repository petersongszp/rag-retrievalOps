# 00-Admin 前端总览与通用操作

## 1. 页面用途

Admin 前端是“面试吧”知识库与评测管理台。源码中页面标题显示为 **RAG Admin**，副标题是 **知识库与评测管理台**。

它提供统一后台外壳，包括：

- 左侧导航菜单
- 顶部面包屑
- 当前知识库选择器
- 当前知识库状态标签
- 刷新按钮
- 中间内容区域

本篇只说明 Admin 前端的通用布局和通用操作。具体“概览”和“知识库”页面请看另外两篇文档。

## 2. 适合谁用

适合这些人使用：

- 需要管理知识库的人
- 需要上传、查看、删除知识库文档的人
- 需要查看入库任务、失败任务的人
- 需要做检索实验、评测、监控、成本、审计、告警的人
- 需要快速切换不同知识库的人

源码中的主要入口路径如下：

| 评测集 | `/evaluation/datasets` | 管理评测数据集 |
| 评测运行 | `/evaluation/runs` | 管理评测任务 |
| 质量监控 | `/quality-monitor` | 质量监控入口 |

## 4. 页面区域

### 4.1 左侧导航区

左侧固定显示后台名称和菜单。

顶部显示：

- **RAG Admin**
- **知识库与评测管理台**

菜单包括：

- 概览
- 知识库
- 检索实验室
- 链路日志
  - 检索日志
  - 入库日志
- 评测
  - 评测集
  - 评测运行
- 质量监控
- 策略中心
- 成本运营
  - 成本看板
  - Vector DB
- 审计中心
- 告警中心
- 报告
  - 周报

左下角有版本提示：

> 当前版本已接入 P4 治理能力骨架，支持成本、向量运维、审计、告警与周报逐步联调。

这是页面展示文案，表示这些治理能力入口已经在前端菜单中出现。

### 4.2 顶部区域

顶部有三类内容：

1. **面包屑**：显示当前页面所在位置。
2. **选择当前知识库**：一个下拉框。
3. **状态标签和刷新按钮**：显示当前知识库，并提供刷新页面按钮。

### 4.3 内容区域

页面主体内容在中间区域展示。点击不同菜单后，这里会切换成对应页面。

## 5. 字段 / 参数含义

### 5.1 当前知识库选择器

顶部下拉框显示所有知识库，选项来自知识库列表接口返回的 `bases`。

主要字段：

| 字段 | 含义 | 页面如何使用 |
|---|---|---|
| `id` | 知识库 ID | 作为下拉框的选中值，也用于跳转 `/knowledge-bases/:id` |
| `name` | 知识库名称 | 作为下拉框显示文字 |
| `description` | 描述 | 在知识库相关页面展示 |
| `vector_collection` | 绑定的向量 collection | 在知识库列表和详情展示 |
| `status` | 知识库状态 | 在知识库列表和详情用标签展示 |
| `created_at` | 创建时间 | 在知识库列表和详情展示 |
| `updated_at` | 更新时间 | 类型中有该字段，但本组页面未直接展示 |

### 5.2 当前知识库本地记忆

前端会把用户当前选择的知识库 ID 存到浏览器本地存储中。

- 存储键名：`admin.selectedKnowledgeBaseId`
- 如果选择了某个知识库：保存它的 ID
- 如果清空选择：删除这个本地存储值
- 下次打开页面时，如果该 ID 仍在知识库列表中，会自动选中它
- 如果没有可用的历史选择，会默认选中列表中的第一个知识库

### 5.3 API 地址配置

源码中接口基础地址为：

- `NEXT_PUBLIC_API_BASE_URL` 环境变量
- 如果没有配置，则默认使用 `/api`

与本组页面直接相关的接口包括：

| 名称 | 地址 | 用途 |
|---|---|---|
| `DASHBOARD_STATS` | `/admin/kb/dashboard/stats` | 概览统计 |
| `METRICS_OVERVIEW` | `/admin/kb/metrics/overview` | 监控指标 |
| `LIST_BASES` | `/admin/kb/bases` | 获取知识库列表 |
| `CREATE_BASE` | `/admin/kb/bases` | 创建知识库 |
| `DELETE_BASE(id)` | `/admin/kb/bases/{id}` | 删除知识库 |
| `UPLOAD_DOCUMENT` | `/admin/kb/documents/upload` | 上传文档 |
| `LIST_DOCUMENTS` | `/admin/kb/documents` | 获取文档列表，可带 `kb_id` |
| `LIST_JOBS_BY_KB(kbId)` | `/admin/kb/jobs?kb_id={kbId}` | 获取某知识库的入库任务 |
| `RETRY_JOB(id)` | `/admin/kb/jobs/{id}/retry` | 重试任务 |
| `CANCEL_JOB(id)` | `/admin/kb/jobs/{id}/cancel` | 取消任务 |

> 说明：表中地址会拼接在 `API_BASE_URL` 后面。

## 6. 按钮 / 操作

### 6.1 左侧菜单点击

点击左侧菜单会跳转到对应页面。

有子菜单的项目可以展开，例如：

- 链路日志
- 评测
- 成本运营
- 报告

### 6.2 选择当前知识库

操作方式：

1. 点击顶部“选择当前知识库”下拉框。
2. 选择一个知识库。
3. 页面会记录该选择。
4. 如果当前正在知识库详情页，选择新知识库后会跳转到新知识库详情页。

如果清空选择：

- 当前知识库变为未选择。
- 顶部标签显示 **未选择知识库**。

### 6.3 刷新按钮

顶部右侧有 **刷新** 按钮。

源码中该按钮执行 `router.refresh()`，意思是刷新当前页面的数据和路由状态。

## 7. 可展开 / 弹窗 / 详情页

### 7.1 可展开菜单

左侧这些菜单有子菜单：

- 链路日志
- 评测
- 成本运营
- 报告

点击后可以展开或收起。

### 7.2 面包屑

面包屑会根据当前路径变化。例如：

- `/dashboard`：显示 **概览**
- `/knowledge-bases`：显示 **概览 / 知识库**
- `/knowledge-bases/:id`：显示 **概览 / 知识库 / 知识库名称**，如果还没有加载到名称，则显示 **知识库详情**
- `/retrieval-lab/debug`：显示 **概览 / 检索实验室 / 调试详情**
- `/evaluation/reports/...`：显示 **概览 / 评测 / 评测运行 / 评测报告**

### 7.3 知识库详情页跳转

当路径是 `/knowledge-bases/:id` 时，页面会根据 `id` 展示某个知识库详情。

如果顶部切换了知识库，且当前在详情页，会跳到新的 `/knowledge-bases/{新ID}`。

## 8. 常见流程

### 流程一：第一次进入后台

1. 打开 `/dashboard`。
2. 等待页面加载知识库列表。
3. 如果有知识库，顶部会自动选择一个知识库。
4. 如果没有知识库，去 `/knowledge-bases` 新建。

### 流程二：切换当前知识库

1. 在顶部下拉框选择知识库。
2. 查看顶部标签，确认当前知识库名称。
3. 如果在详情页，页面会跳转到新知识库详情。

### 流程三：刷新当前页面

1. 点击顶部 **刷新**。
2. 等待页面重新加载。

### 流程四：从导航进入知识库管理

1. 点击左侧 **知识库**。
2. 进入 `/knowledge-bases`。
3. 可新建、打开或删除知识库。

## 9. 注意事项

- 如果接口返回 403，页面会显示“权限不足”提示，需要联系管理员确认权限配置。
- 顶部选择的知识库会保存在浏览器本地，不是服务端配置。
- 如果本地保存的知识库 ID 已经不存在，前端会自动改选列表中的第一个知识库，或者变成未选择。
- 左侧菜单中有些页面只是入口，本篇不展开说明具体业务功能。
- `Contract gap` 是页面用于显示“接口字段缺失或空值”的兜底文字，不代表用户需要输入这个值。
